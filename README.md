# 📋 Πίνακες Αναπληρωτών — Έλεγχος Μορίων/Τοποθέτησης

Εργαλείο ελέγχου πινάκων κατάταξης αναπληρωτών εκπαιδευτικών: κλάδος, τοποθεσία-στόχος,
μόρια — και βλέπεις πού θα έμπαινες, βάσει δημόσιων στοιχείων του Υπουργείου Παιδείας.

**🌍 Ζωντανή έκδοση:** [anaplhrwtes.onrender.com](https://anaplhrwtes.onrender.com)
*(δωρεάν φιλοξενία — αν δεν έχει επισκέψεις για ~15 λεπτά "κοιμάται", οπότε το πρώτο
άνοιγμα μπορεί να αργήσει έως ένα λεπτό)*

⚠️ **Ανεπίσημο εργαλείο.** Δεν έχει καμία σχέση με το Υπουργείο Παιδείας, το ΑΣΕΠ ή τη
Δ.ΥΠ.Α. Τα αποτελέσματα είναι όσο καλά είναι τα αρχεία που φορτώνονται — πάντα να
επιβεβαιώνεις κρίσιμες αποφάσεις με τις επίσημες ανακοινώσεις/πίνακες.

---

## Τι κάνει

| Καρτέλα / εντολή | Τι δείχνει |
|---|---|
| 🎯 **Γρήγορος έλεγχος** (`predict`) | Δίνεις κλάδο + τοποθεσία-στόχο + μόρια → βλέπεις σε ποια φάση/περιοχή θα έμπαινες φέτος, βάσει ιστορικών ετών. Δείχνει επίσης μέσο όρο ημερομηνιών ανά φάση και τον πίνακα μοριοδότησης. |
| 📊 **Πλήρης Ανάλυση** (`full`) | Πλήρης ανάλυση ενός κλάδου: αφαίρεση μονίμων (με ονόματα/μόρια/θέση όσων αφαιρέθηκαν), προαιρετική αφαίρεση όσων ήδη προσλήφθηκαν σε συγκεκριμένα έτη, βάσεις ανά περιοχή, αρχείο επαλήθευσης. |
| 🔍 **Σύνοψη Κλάδου** (`summary`) | Πλήθος υποψηφίων, μόρια 1ου/τελευταίου, κατανομή κατά παιδαγωγική επάρκεια. |
| 🧭 **Βάση Φάσης** (`phase`) | Πόσα μόρια χρειάστηκε ο τελευταίος σε μια περιοχή, ανά φάση ή για ολόκληρο το σχολικό έτος. |
| 🚀 **Αναβαθμίσεις** (`upgrades`) | Ποιοι προσλήφθηκαν με ΜΕΙΩΜΕΝΟ ωράριο και αναβαθμίστηκαν σε ΠΛΗΡΕΣ στην επόμενη φάση. |
| 📥 **Αρχεία αποτελεσμάτων** | Λήψη των Excel που παράγει κάθε ανάλυση. |

## Δομή αρχείων

```
.
├── main.py                  # Η κύρια λογική· τρέχει και σκέτο ως CLI (python main.py <εντολή>)
├── config.py                # Ρυθμίσεις: φάκελος δεδομένων, ονομασίες στηλών, μοριοδότηση φάσεων
├── loader.py                # Ανάγνωση Excel/CSV, εντοπισμός επικεφαλίδων
├── normalize.py             # Κανονικοποίηση κειμένου/κωδικών κλάδου/φάσης-έτους
├── pipeline.py               # Κατάταξη, αφαίρεση μονίμων, στατιστικά ανά περιοχή/φάση
├── audit.py                  # Αρχείο επαλήθευσης (AUDIT_*.xlsx)
├── webapp.py                  # Η ιστοσελίδα (Flask) — αυτό τρέχει στο Render
├── app.py                     # Desktop έκδοση με παράθυρα (tkinter), προαιρετική
├── share_with_friend.py        # Προσωρινό δημόσιο link μέσω ngrok, για γρήγορη δοκιμή
├── Dockerfile / requirements.txt / .dockerignore   # Για το hosting στο Render
└── data/
    ├── pinakes/               # Πίνακες κατάταξης ανά κλάδο (π.χ. ΠΕ06.xlsx)
    ├── monimoi/                # Αρχεία διορισμών/μονίμων
    ├── faseis/                  # Αρχεία ανά φάση πρόσληψης, οργανωμένα ανά σχολικό έτος
    ├── faseis_dates.json         # Πραγματικές ημερομηνίες ανάληψης υπηρεσίας ανά φάση/έτος
    └── moriodotisi.json           # Πίνακας μοριοδότησης (Ν. 5078/2023, ΦΕΚ 211/Α/20.12.2023)
```

## Πώς το τρέχεις τοπικά

**Γραμμή εντολών** (χρειάζεται μόνο `pandas` + `openpyxl`):
```
python main.py inspect
python main.py summary --klados ΠΕ06
python main.py full --klados ΠΕ06 --region Χανίων
python main.py phase --klados ΠΕ06 --region Χανίων
python main.py predict --klados ΠΕ06 --region "Α' ΕΒΡΟΥ" --moria 50.8
python main.py upgrades --klados ΠΕ06
```

**Ιστοσελίδα τοπικά** (χρειάζεται επιπλέον `pip install flask`):
```
python webapp.py
```
Ανοίγει μόνο του στο `http://127.0.0.1:5000`.

**Desktop παράθυρο** (tkinter, έρχεται έτοιμο με το Python):
```
python app.py
```

## Ενημέρωση δεδομένων

- Νέος πίνακας κλάδου → μπαίνει στο `data/pinakes/`.
- Νέα φάση πρόσληψης → μπαίνει στο `data/faseis/<σχολικό έτος>/`, με το ίδιο μοτίβο
  ονομασίας (φάση + έτος) που έχουν ήδη τα υπόλοιπα αρχεία εκεί.
- Νέες ημερομηνίες/μοριοδότηση → επεξεργασία του `faseis_dates.json` / `moriodotisi.json`.
- Μετά από κάθε αλλαγή: commit + push στο GitHub — το Render ξαναχτίζει μόνο του σε
  2-3 λεπτά.

## Άδεια / προέλευση δεδομένων

Τα στοιχεία μοριοδότησης προέρχονται από τον Ν. 5078/2023 (ΦΕΚ 211/Α/20.12.2023) και
τις προκηρύξεις ΑΣΕΠ. Οι πίνακες κατάταξης είναι δημόσια στοιχεία του Υπουργείου
Παιδείας. Η νομοθεσία και οι πίνακες ενημερώνονται — έλεγχε πάντα τις επίσημες πηγές
για ό,τι αφορά την προσωπική σου περίπτωση.
