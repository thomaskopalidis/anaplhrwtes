# 📋 Πίνακες Αναπληρωτών — Έλεγχος Μορίων/Τοποθέτησης

Εργαλείο ελέγχου πινάκων κατάταξης αναπληρωτών εκπαιδευτικών: κλάδος, τοποθεσία-στόχος,
μόρια — και βλέπεις πού θα έμπαινες, βάσει δημόσιων στοιχείων του Υπουργείου Παιδείας.
Δείχνει επίσης χάρτες περιοχής/νομού, εκτιμώμενο μισθολόγιο, και έχει ενσωματωμένο
βοηθό AI (eduAI) για ερωτήσεις.

**🌍 Ζωντανή έκδοση:** [anaplhrwtes.onrender.com](https://anaplhrwtes.onrender.com)
*(δωρεάν φιλοξενία — αν δεν έχει επισκέψεις για ~15 λεπτά "κοιμάται", οπότε το πρώτο
άνοιγμα μπορεί να αργήσει έως ένα λεπτό)*

⚠️ **Ανεπίσημο εργαλείο.** Δεν έχει καμία σχέση με το Υπουργείο Παιδείας, το ΑΣΕΠ ή τη
Δ.ΥΠ.Α. Τα αποτελέσματα είναι όσο καλά είναι τα αρχεία που φορτώνονται — πάντα να
επιβεβαιώνεις κρίσιμες αποφάσεις με τις επίσημες ανακοινώσεις/πίνακες.

## Τι κάνει

| Καρτέλα / εντολή | Τι δείχνει |
|---|---|
| 🎯 **Γρήγορος έλεγχος** (`predict`) | Δίνεις κλάδο + τοποθεσία-στόχο + μόρια → βλέπεις σε ποια φάση/περιοχή θα έμπαινες φέτος, βάσει ιστορικών ετών (2025-2026 και μετά). Δείχνει επίσης: ✅/❌ ετυμηγορία, επίσημη σύνοψη θέσης στον πίνακα, διαδραστικό χάρτη νομού/νησιού με χρωματισμένα όρια, χάρτη σχολικών μονάδων (ΠΣΔ), μέσο όρο ημερομηνιών ανά φάση, πίνακα μοριοδότησης, μισθολογικά κλιμάκια, έλεγχο δικαιώματος επιδόματος παραμεθορίου, και λοιπά επιδόματα. |
| 📊 **Πλήρης Ανάλυση** (`full`) | Πλήρης ανάλυση ενός κλάδου: αφαίρεση μονίμων (με ονόματα/μόρια/θέση όσων αφαιρέθηκαν), προαιρετική αφαίρεση όσων ήδη προσλήφθηκαν σε ένα ή περισσότερα έτη μαζί, βάσεις ανά περιοχή, αρχείο επαλήθευσης. |
| 🔍 **Σύνοψη Κλάδου** (`summary`) | Πλήθος υποψηφίων, μόρια 1ου/τελευταίου, κατανομή κατά παιδαγωγική επάρκεια. |
| 🧭 **Βάση Φάσης** (`phase`) | Πόσα μόρια χρειάστηκε ο τελευταίος σε μια περιοχή, ανά φάση ή για ολόκληρο το σχολικό έτος. |
| 🚀 **Αναβαθμίσεις** (`upgrades`) | Ποιοι προσλήφθηκαν με ΜΕΙΩΜΕΝΟ ωράριο και αναβαθμίστηκαν σε ΠΛΗΡΕΣ στην επόμενη φάση, με σύνοψη βάσης (χαμηλότερο μόριο + θέση τότε/τώρα) ανά φάση. |
| 📥 **Αρχεία αποτελεσμάτων** | Λήψη των Excel που παράγει κάθε ανάλυση. |
| 💬 **eduAI** | Κουμπί κάτω-δεξιά σε κάθε σελίδα — μικρός βοηθός AI (Google Gemini) που απαντάει ερωτήσεις για μόρια, φάσεις και τη χρήση της εφαρμογής. |

## Άλλα χαρακτηριστικά

- **Χάρτες:** κάθε τοποθεσία-στόχος στη Γρήγορη Ανάλυση δείχνει διαδραστικό χάρτη (OpenStreetMap) με
  χρωματισμένο το όριο του νομού/νησιού/δήμου, μπλε σημαδάκι με το ακριβές όνομα (κλικ/άγγιγμα για
  popup), και τον επίσημο χάρτη σχολικών μονάδων του Πανελλήνιου Σχολικού Δικτύου δίπλα του.
  Αναγνωρίζει ειδικές υποπεριοχές (π.χ. "Β' Έβρου" = Σαμοθράκη, "Α' Αθήνας", "Α' Θεσ/νίκης") μέσω
  του `subregions.json`.
- **Μισθολογικά/επιδόματα:** πίνακας μισθολογικών κλιμακίων, αυτόματος έλεγχος αν η περιοχή που
  έψαξες δικαιούται επίδομα παραμεθορίου (βάσει επίσημης λίστας ΦΕΚ), και πίνακας λοιπών επιδομάτων
  (οικογενειακό κ.λπ.).
- **Σκοτεινό θέμα, αντιγραφή αποτελέσματος, favicon.**
- **Cache + προθέρμανση εκκίνησης:** τα αρχεία φάσεων/πινάκων φορτώνονται μία φορά και μένουν στη
  μνήμη· ξαναφορτώνονται μόνο αν αλλάξει το ίδιο το αρχείο. Ο server προθερμαίνει μόνος του την cache
  μόλις ξεκινήσει, πριν έρθει ο πρώτος επισκέπτης.
- **Στατιστικά ΕΛΣΤΑΤ** (Νηπιαγωγεία/Δημοτικά, Γυμνάσια, Λύκεια) στη δεξιά στήλη, για γενικό context.

## Πώς το τρέχεις τοπικά

**Γραμμή εντολών** (χρειάζεται μόνο `pandas` + `openpyxl`):
```
python main.py inspect
python main.py summary --klados ΠΕ06
python main.py full --klados ΠΕ06 --region Χανίων
python main.py phase --klados ΠΕ06 --region Χανίων
python main.py predict --klados ΠΕ06 --region "Α' ΕΒΡΟΥ" --moria 50.8
python main.py upgrades --klados ΠΕ06
```

**Ιστοσελίδα τοπικά** (χρειάζεται επιπλέον `pip install flask`):
```
python webapp.py
```
Ανοίγει μόνο του στο `http://127.0.0.1:5000`.

**Desktop παράθυρο** (tkinter, έρχεται έτοιμο με το Python):
```
python app.py
```

### Ρύθμιση eduAI (προαιρετικό)

Το κουμπί eduAI χρειάζεται δωρεάν κλειδί από το [Google AI Studio](https://aistudio.google.com)
(Get API key → Create API key — χωρίς κάρτα, **μην ενεργοποιήσεις billing** στο πρότζεκτ, αλλιώς
χάνεται το δωρεάν όριο). Βάλε το κλειδί ως μεταβλητή περιβάλλοντος `GEMINI_API_KEY`:
- **Τοπικά:** `export GEMINI_API_KEY=το_κλειδί_σου` πριν τρέξεις `python webapp.py`.
- **Render:** Dashboard → το service → Environment → Add Environment Variable.

Χωρίς αυτήν τη μεταβλητή, το eduAI απαντάει απλά ότι δεν έχει ρυθμιστεί — δεν επηρεάζει τίποτα
άλλο στην εφαρμογή.

## Ενημέρωση δεδομένων

- Νέος πίνακας κλάδου → μπαίνει στο `data/pinakes/`.
- Νέα φάση πρόσληψης → μπαίνει στο `data/faseis/<σχολικό έτος>/`, με το ίδιο μοτίβο
  ονομασίας (φάση + έτος) που έχουν ήδη τα υπόλοιπα αρχεία εκεί.
- Νέες ημερομηνίες/μοριοδότηση/υποπεριοχές/μισθολογικά/επιδόματα → επεξεργασία του αντίστοιχου
  αρχείου JSON μέσα στο `data/`.
- Μετά από κάθε αλλαγή: commit + push στο GitHub — το Render ξαναχτίζει μόνο του σε
  2-3 λεπτά.

## Άδεια / προέλευση δεδομένων

Τα στοιχεία μοριοδότησης προέρχονται από τον Ν. 5078/2023 (ΦΕΚ 211/Α/20.12.2023) και
τις προκηρύξεις ΑΣΕΠ. Τα στοιχεία παραμεθορίου/επιδομάτων προέρχονται από τον ν.4024/2011 και το
ΦΕΚ 667/Β/11-11-1992. Οι πίνακες κατάταξης είναι δημόσια στοιχεία του Υπουργείου Παιδείας. Τα
στατιστικά infographics προέρχονται από την Ελληνική Στατιστική Αρχή (ΕΛΣΤΑΤ). Η νομοθεσία και οι
πίνακες ενημερώνονται — έλεγχε πάντα τις επίσημες πηγές για ό,τι αφορά την προσωπική σου περίπτωση.
