# Πίνακες Αναπληρωτών — Έλεγχος Μορίων/Τοποθέτησης

Εργαλείο ελέγχου πινάκων κατάταξης αναπληρωτών εκπαιδευτικών (κλάδος,
τοποθεσία, μόρια), βασισμένο σε δημόσια στοιχεία του Υπουργείου Παιδείας.

Δώσε κλάδο (ΠΕ), τοποθεσία-στόχο και τα μόριά σου για να δεις πού θα
έμπαινες, ή εξερεύνησε τις υπόλοιπες καρτέλες (πλήρης ανάλυση, βάση φάσης,
αναβαθμίσεις μειωμένου ωραρίου).
